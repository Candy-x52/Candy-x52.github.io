# piggy 的个人作品集

金融背景 · AI 产品实践。

展示中南讲座助手、长文案编写 Agent 学习实践、家庭菜谱微信小程序与 CPA 财管公式词典。

网站为原生 HTML/CSS/JavaScript，无需安装依赖或运行构建命令。通过 GitHub Pages 从 main 分支根目录发布。

## 在线访问

https://candy-x52.github.io/

## 维护

- `index.html`：个人介绍和项目卡片。
- `styles.css`：作品集样式。
- `assets/`：项目图片与演示配图。
- `demos/agent.html`：交互流程图，结构示意，不调用模型。
- `demos/menu.html`：根据微信小程序源码重绘的网页演示，非微信运行截图；选菜与库存状态只在本页暂存。

在当前目录运行 `python3 -m http.server 8080` 可本地预览。

项目截图中的校园活动、人数与评分含虚构演示数据，不代表真实校园业务。仓库不包含凭据、私有家庭设置、原始 Agent 工作流或 Sites 托管配置。
