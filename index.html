看看我是怎么做的 ＋

学生端：从发现到沉淀

筛选和收藏讲座，结合专业、兴趣与课表空闲生成规则推荐，显示冲突提示；生成行前清单、导出 .ics 日历文件，记录听讲收获并导出 Markdown。往期资料库保留 116 条公开历史记录及来源链接。

教师端：从发布到反馈

提供讲座新建、编辑、发布与撤回；通知文字规则预填后人工核对，资料保存后进入待发布流程。支持报名审核与 CSV 导出、提问管理、口令签到、评分和留言汇总的本地演示。

产品与体验实践

围绕学生与教师两个角色组织页面与操作流程，使用 AI 工具辅助开发。新版包含浅色 / 暗色主题、响应式布局、个人资料备份与恢复，以及随滚动切换的三幕首页。

当前边界

纯前端原型，学生端与教师端仅在同一浏览器内共享本地数据，不是跨设备在线业务系统。讲座包含公开历史资料与明确标注的模拟数据；不实时采集网站、不调用大模型，海报 OCR 为预置演示，也不对接真实报名、签到或在线日历服务。

以 Dify 长文写作案例为学习对象，围绕「大纲规划 → 章节扩写 → 正文汇总」拆解三个应用之间的数据流。

查看工作流拆解 ＋

案例解决什么问题

面对带有主题、人物、目的、写作风格与字数要求的长文，先生成结构化章节，再按章扩写与汇总，而不是一次性要求模型输出整篇文章。

三个应用怎样配合

主 Chatflow 负责规划与章节迭代；循环扩写子流程接收主题、字数与背景，通过字符统计和循环条件控制扩写；Tool-StyleChecker 接收目标风格与待检查文本，生成风格分析、建议与修订文本。

学习记录关注什么

沿节点追踪输入输出、JSON 解析和 HTTP 调用，区分主流程的章节拼接与子流程的历史覆盖；辨认「已配置工具」和「运行中确实调用」的差别，并检查背景如何传入下一章。

当前阶段与来源

基于教程笔记、三个 YAML 工作流和本地学习清单整理的案例学习展示。尚无完整端到端运行验证记录，不将教程中的行业扩展、事实核验或发布集成列为已实现成果。当前不提供在线 Agent 运行入口；流程可视化仅用于解释结构。

03微信原生小程序 · 本地 MVP
16 道内置菜谱食材图鉴库存记录

家庭菜谱小程序

从决定吃什么，到知道家里还剩什么。

把自由选菜、菜谱维护、食材识别与调料余量放在一起，让家庭做饭前的准备更有头绪。

了解项目 ＋

选菜与今日菜单

内置 8 道荤菜和 8 道素菜，可按分类与关键词筛选、收藏，自由加入今日菜单并统计荤素数量。详情展示份量、食材、步骤、耗时、难度与贴士。

让菜谱适合自己家

支持新增、编辑和删除自建菜谱，为菜谱拍照或选图；内置菜谱也可在本地修改并恢复默认。可记录改进心得，保存并复制菜谱参考链接。

食材图鉴与余量记录

按大类和细分类维护食材、别名、识别提示及照片，菜谱中的食材标签可跳转资料。普通食材以百分比滑杆记录剩余量，调料和香料以瓶中液面与滑杆表示库存；库存不改变烹饪用量。

使用边界

可添加或移除需排除的食材关键词，按菜谱食材名称匹配并过滤。数据与图片保存在微信本地，无后端、无账号、无多设备同步；清除缓存会清除自定义内容。源码支持微信开发者工具预览，尚未提供公开小程序体验码。
